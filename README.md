# 進捗管理（司法書士試験）

司法書士試験に向けた学習進捗の PWA です。ホームからテキストまとめ・択一対策・スピードチェックへ進みます。

## 公開URL

https://tanatos0209.github.io/shoshi-sogo/

パスは `/shoshi-sogo/` です。画像・CSS・JS・manifest は相対パスにしてあるので、このサブパスのまま配信できます。

GitHub Pages は **Settings → Pages → Build and deployment → Deploy from a branch → Branch: `main` / Folder: `/ (root)`** です。このリポジトリは既にその設定です。`main` に載ると上記 URL に出ます。

## 使い方

- **択一対策** と **今日の学習を開始** は、別リポジトリの択一アプリ（https://tanatos0209.github.io/shoshi-ox/ ）を同じタブで開きます。
- **テキストまとめ** と **スピードチェック** は入り口だけあり、中身は準備中です。
- **記録する** で、今日の学習時間の追加、解いた問題数、メイン／マイナー科目の択一・記述の進捗を手入力できます。
- **設定** で試験日、1日の目標時間、週の目標時間、1日の目標問題数を変更できます。初期の試験日は、開いた日から 150 日後です。
- **パーフェクトコントロール** と **カレンダー** は準備中です。
- データはこの端末の localStorage に保存されます。ホーム画面に追加すると、承認済みアイコンで起動できます。

## ローカル確認

```bash
python3 -m http.server 4173
```

ブラウザで http://127.0.0.1:4173/ を開きます。
